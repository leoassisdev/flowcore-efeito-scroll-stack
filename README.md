## Como instalar

1. **Instale as dependências**

   ```bash
   npm install lenis
   ```

2. **Crie src/components/ScrollStack.tsx** Copie o conteúdo de `src/ScrollStack.tsx` e `src/ScrollStack.css` deste repositório. Esse efeito também tem ScrollStack.css: crie ao lado.
3. **Use na página**

   ```tsx
   <ScrollStack><ScrollStackItem>Card 1</ScrollStackItem></ScrollStack>
   ```
